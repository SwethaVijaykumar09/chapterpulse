# ChapterPulse
Reader Engagement Predictor for Serialized Fiction (T.Y.B.Sc. Data Science project).

## Data and credit
Built on the Asianfanfics archive on Hugging Face (licence CC-BY-SA-4.0): https://huggingface.co/datasets/trentmkelly/asianfanfics

This repository contains only numbers calculated from chapters (word counts, sentence lengths and similar), a trained model, an original sample story and the app code. It contains no story text from the dataset and no usernames.

## Limits
The model finds patterns associated with engagement. It does not prove cause. Text features alone explained very little on unseen stories.
